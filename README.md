# pi-web-access

Web search and URL fetch tools for the pi coding agent.

## Installation

```bash
npm install pi-web-access
```

## Features

- **web-search** — Search the web using a search engine
- **web-fetch** — Fetch and retrieve content from URLs

## Usage

These extensions provide the `web_search` and `web_fetch` commands to the pi coding agent for accessing web content.
